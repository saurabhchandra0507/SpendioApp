# Spendio

A simple expense tracker for Android, built with Jetpack Compose and Room.

## Features

- Add expenses with a category, date, and description
- View your balance and expense history on the home screen
- Delete expenses with a confirmation dialog
- EMI calculator for loan payments
- Profile screen

## Tech Stack

- Kotlin
- Jetpack Compose (Material 3)
- Compose Navigation
- Room (local database)
- Min SDK 24, Target SDK 37

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/saurabhchandra0507/SpendioApp.git
   ```
2. Open the project in Android Studio.
3. Build and run on an emulator or device, or from the command line:
   ```bash
   ./gradlew installDebug
   ```

## Running Tests

```bash
./gradlew testDebugUnitTest
```
